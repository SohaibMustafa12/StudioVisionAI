# Studio Vision AI 3.0

**An all-in-one creative studio for Windows: text-to-speech with 400+ voices, voice cloning, a live voice
interpreter, a QR code designer and scanner, a logo and brand-kit generator, and a business-card maker.**

Free to use: no API keys, no accounts, no subscriptions. Everything you make stays on your own computer.

## ⬇️ Download

**[Download Studio Vision AI for Windows](https://github.com/SohaibMustafa12/StudioVisionAI/releases/latest/download/StudioVisionAI-3.0.0-portable.zip)**
(Windows 10 / 11, 64-bit)

1. Click the link above. The zip downloads straight away.
2. Right-click the zip → **Extract All**.
3. Open the extracted folder and double-click **Install.cmd**.
4. Studio Vision AI opens, and you'll find it on your Desktop and in the Start menu.

> If Windows shows *"Windows protected your PC"*, click **More info → Run anyway**. The app isn't signed with
> a paid code-signing certificate, which is normal for student and open-source projects.

No admin rights and no Python are needed. To uninstall: **Settings → Apps → Installed apps → Studio Vision AI**.

## ✨ Features

The app has six tabs (studios). Switch between them with `Ctrl+1` … `Ctrl+6`.

### 🎙️ Voice Studio
Turn any text into natural speech.

**Four voice engines**
| Engine | What it is | Needs internet |
|---|---|---|
| 🌍 **Edge Neural voices** | 400+ Microsoft neural voices in dozens of languages and accents, filterable by gender (Any / Male / Female), with featured voices tagged (e.g. "Anime style", "K-drama") | Yes |
| 🗣️ **Google voice** | Google Text-to-Speech for every supported language, with a choice of English accent and a **Slow & clear** mode | Yes |
| 🧬 **My cloned voice (F5-TTS)** | Clones a voice from a short recording, then speaks any text in that voice. Quality: ⚡ Fast (8 steps), ⚖️ Balanced (16), 💎 Best (32) | No (offline) |
| 💻 **System voices** | The voices built into Windows | No (offline) |

**Text & translation**
- Type or paste text, open a `.txt` file, or insert a sample script.
- Translate the text into 30 languages before speaking (Urdu, English, Hindi, Arabic, Punjabi, Bengali, Persian,
  Turkish, Spanish, French, German, Italian, Portuguese, Russian, Japanese, Korean, Chinese (Simplified &
  Traditional), Dutch, Polish, Ukrainian, Indonesian, Malay, Vietnamese, Thai, Tamil, Telugu, Swahili, Greek,
  Swedish).
- **⇅ Use translation as my text** replaces your text with the translation.
- Automatic language detection, plus **Auto-match the voice to the language** so a voice never goes silent on
  text it can't pronounce.

**Sound controls**
- **Speed** (−50% to +100%) and **Pitch** (Edge voices).
- **10 voice effects:** 🤖 Robot, 📻 Old radio, ☎️ Telephone, 🏟️ Stadium hall, 🔁 Echo canyon, 🐿️ Chipmunk,
  👹 Giant / deep, 🌊 Underwater, 📢 Megaphone, 👽 Alien.
- **Background music:** 🌙 Calm pad, ☕ Lo-fi beat, 🎬 Cinematic drone (all generated by the app), or 🎵 your
  own music file, with a music-volume slider.

**🎭 Dialogue mode**
Write a script with several speakers and each speaker automatically gets its own distinct voice.

**Karaoke & subtitles**
- Words light up as they are spoken (karaoke highlighting). For voices that don't report word timings, the
  offline Whisper model works out the timings.
- **💬 Export subtitles** as `.srt` or `.vtt`.

**Playback & export**
- ⚡ Speak (`Ctrl+Enter`), ⏯ Pause, ⏹ Stop (`Esc`), 🔁 Replay, ▶ Preview a voice.
- **💾 Save audio** as MP3, WAV, OGG or FLAC.

**Voice profiles (for cloning)**
- 🔴 **Record** your voice with the microphone, or 📥 **Import an audio file** (WAV / MP3 / FLAC / OGG).
- Profiles are saved, named, and reusable; the app transcribes the sample automatically.

### 🌐 Live Interpreter
Speak in one language and hear it in another, like a personal interpreter.

- **Talk → transcribe → translate → speak**, shown as a chat.
- 🎙 **Tap to talk**, or press `Space` while the interpreter tab is open.
- Choose **I speak** and **Translate to** languages; **⇄** swaps them.
- **Recogniser:** Auto (offline if available), Offline Whisper (private, nothing leaves your PC) or Online Google
  (fast).
- **Offline model size:** base (fast, 140 MB), small (better, 460 MB), medium (best, 1.5 GB).
- **Conversation mode:** swaps languages after each turn, so two people can talk back and forth.
- **Stop listening automatically when I pause.**
- **Speak the translation aloud**, with a choice of voice (Any / Female / Male).
- **Type mode:** type instead of talking.
- **💾 Export chat** and **🧹 Clear**.

### ✨ QR Studio
Design QR codes that look good and still scan.

**9 content types**
| Type | What it encodes |
|---|---|
| 🔗 Link / Text | Any URL or text |
| 📶 Wi-Fi | Network name, password, security (WPA / WEP / none), hidden network. Phones join with one scan. |
| ✉️ Email | Address, subject and message |
| 📞 Phone | A number to call |
| 💬 SMS | Number and pre-filled message |
| 🟢 WhatsApp | Opens a WhatsApp chat with a pre-filled message |
| 👤 Contact card | vCard: name, company, job title, phone, email, website, address |
| 📍 Location | Latitude / longitude |
| 📅 Event | Calendar event with title, start, end, location, description |

**Styling**
- **Module shapes:** Square, Rounded, Dots, Gapped, Vertical Bars, Horizontal Bars.
- **Eye (corner) shapes:** Square, Rounded, Dots, Gapped.
- **Colours:** solid, or Radial / Square / Horizontal / Vertical gradients.
- **Error correction:** Low (7%), Medium (15%), Quartile (25%), High (30%), best when adding a logo.
- **🖼️ Picture QR:** blends a photo into the code, with a **Photo visibility** slider.
- **Logo & caption:** put a logo in the centre (your own image or your Logo Studio logo) with a size slider,
  and add a caption such as "SCAN ME".
- **Scan score:** every design is checked with 5 scan tests so you know it will actually work.

**Scanning & batch**
- 📷 **Webcam** scanner (choose the camera), 🖼️ **From image**, 📋 **From clipboard**.
- Scanned results can be copied, opened, or **✨ Restyled as my QR**.
- 📑 **Batch from CSV:** generate hundreds of QR codes at once from a spreadsheet.

**Export:** PNG, JPG, WebP, **SVG** (vector), PDF, and **🎞 animated** GIF / WebP; choose the size; 📋 copy to
clipboard.

### 🎨 Logo Studio
Generate a logo and a complete brand kit from your brand name.

- **14 icon styles:** Orbit Rings, Hexagon Badge, Shield Crest, Circle Monogram, App Icon, Sun Burst,
  Diamond Stack, Venn Blend, Mountain Peak, Identicon Grid, Letter Mark, Lotus Petals, Neon Ring, Isometric Cube.
- **4 layouts:** Icon above text, Icon beside text, Icon only, Text only.
- **5 backgrounds:** Dark, Gradient, Light, Brand colour, Transparent.
- **12 palettes:** Neon, Sunset, Ocean, Forest, Royal, Fire, Mint, Gold Luxe, Candy, Cyberpunk, Earth, Mono, plus
  custom colours.
- Text options: font, **Gradient text**, **Glow**, **UPPERCASE**, **Letter spacing**, **Variation seed** (🎲).
- **🎲 Surprise me** and **🧩 6 variations** (optionally **Keep my colours** / **Keep icon style**).
- **🧳 Export brand kit:** about 20 files in one click: logos, favicons, app icons, social-media banners and a
  colour-palette sheet.
- **🎬 Animated intro** (GIF).
- **💾 Save**, **📋 Copy**, **➡ Put in QR**, **🪪 Design a business card with this logo**.

### 🪪 Card Studio
Business cards built from your Logo Studio brand plus a contact QR code.

- Fields: full name, job title, company, phone, email, website, city / address.
- **5 templates:** Midnight, Clean White, Gradient Wave, Split Panel, Neon Edge (**🔀 Next template** cycles them).
- The QR on the card saves all your details straight into a phone's contacts.
- Colours, font and logo follow Logo Studio (**🎨 Edit logo & colours**).
- **Export:** 💾 front + back PNG, 📄 2-page PDF, 🖨️ **A4 print sheet** (10 cards with crop marks), 📋 copy the front.
- **⇣ Copy into my QR contact card** fills the QR Studio contact card with the same details.

### 🕘 History
Everything you create is saved automatically: audio, QR codes, logos, cards and interpreter chats.

- Searchable, and filterable by type (Audio, QR, Logo, Card, Interpreter).
- ▶ **Play** audio again, ♻️ **Restore settings** (reopen a QR / logo / card exactly as it was),
  💾 **Export a copy**, 📂 **Show file**, 🗑 **Delete**, 🧹 **Clear all**, 📂 **Open folder**.

### 🪟 Works anywhere in Windows
- **Read any text aloud:** select text in any app (browser, Word, PDF…) and press `Ctrl+Alt+S`.
- **Translate & read:** select text and press `Ctrl+Alt+T` to hear it in your Voice Studio target language.
- **Bring the app up from anywhere:** `Ctrl+Alt+V`.
- A **floating mini-player** shows what's being read.
- **System tray:** closing the window keeps the app in the tray so hotkeys keep working. The tray menu has
  Show, Read clipboard aloud, Stop speaking, Settings and Quit.
- Optional **start with Windows** (open the window, or start quietly in the tray).

## ⚙️ Settings
Open with `Ctrl+,`, the ⚙ button, or the tray menu.

- **🎨 Appearance:** theme (Dark, Light, Midnight AMOLED), accent colour (Indigo, Pink, Emerald, Amber, Ocean,
  Violet), animations & motion effects on/off.
- **⌨️ Speak anywhere:** hotkeys for *Read selection* and *Translate & read*, and the floating mini-player.
- **⚡ Speed:** *Get everything ready when the app opens* preloads the Whisper and voice-cloning models in the
  background (uses about 2–3 GB of memory; on PCs with less RAM the cloning model waits until it's needed). A
  badge in the header shows progress.
- **🛠️ Repair:** *Repair voice engine* updates the Edge voice library if Microsoft changes its voice service.
- **🪟 Windows:** keep running in the tray, start with Windows (off / open window / quietly in tray), the
  "bring the app up" hotkey, and **Open data folder**.

Every setting and every field you fill in is remembered between launches.

## 🔒 Your data & privacy
- **Each person's data stays on their own PC**, separately for each Windows user account. Nothing is shared
  between installs, and nothing is uploaded to any server owned by this app.
- Where things are kept:
  - History, voice profiles, logs: `%APPDATA%\StudioVisionAI`
  - Settings: the Windows registry under `HKEY_CURRENT_USER\Software\StudioVisionAI`
- Uninstalling the app **keeps** this data. Delete `%APPDATA%\StudioVisionAI` yourself to remove it.
- Wi-Fi passwords typed into QR Studio are never saved.
- Online features send only the text or audio they need to the service doing the work: Edge voices
  (Microsoft), Google voice / Google translation / Google speech recognition (Google). The offline engines
  (Whisper, F5-TTS, system voices) never leave your PC.

## 🐍 Running from source
Requires Python 3.10+ (3.12 recommended) on Windows.

```bash
pip install -r requirements.txt
python studio_vision.pyw
```

Optional, for offline voice cloning and offline speech recognition (large downloads):
```bash
pip install f5-tts faster-whisper
```
The packaged app uses these from a normal Python install on the same PC if they are present. Everything else
works without them.

## 🏗️ Building & installing

| Command | What it does |
|---|---|
| `powershell -ExecutionPolicy Bypass -File build_and_install.ps1` | Builds the app and installs it on **this** PC (Desktop + Start menu shortcuts, Installed-apps entry). Use after editing the code. |
| `powershell -ExecutionPolicy Bypass -File build_release.ps1` | Builds files to **share** in `release\`: `StudioVisionAI-<ver>-portable.zip` (unzip → `Install.cmd`) and, if Inno Setup 6 is installed, `StudioVisionAI-Setup-<ver>.exe`. |
| `tools\build_exe.ps1` | The shared build step used by both scripts (creates a build environment, renders the icon, runs PyInstaller). |
| `python tools\make_icon.py` | Re-renders the app icon (`assets\app.ico`, `assets\app_logo.png`) with the app's own logo engine. |
| `uninstall.ps1` | Removes the installed app, shortcuts and start-up entry (keeps your data). |

**Releases on GitHub:** publishing a release runs `.github/workflows/release.yml`, which builds the app on a
Windows machine in GitHub Actions and attaches the download zip to the release automatically. It can also be
run by hand from the **Actions** tab.

## ✅ Self-test
The app includes 37 automated end-to-end checks that drive the real interface: startup, every tab, all voice
engines, translation, language detection, karaoke timing, effects, dialogue mode, every audio and subtitle
format, the interpreter (typed, recognition, microphone), all 9 QR types, 84 QR style combinations (each one
verified to scan), logos and picture QRs, every export format, scanning, CSV batch, Wi-Fi password privacy, all
14 logo styles × 4 layouts, brand kit, all 5 card templates, history, themes, command palette, hotkeys, tray,
drag & drop, error handling, preloading and voice cloning.

It runs in a **sandbox** (a separate temporary data folder and settings), so it never touches your history or
preferences.

```bash
"%LOCALAPPDATA%\Programs\Studio Vision AI\Studio Vision AI.exe" --selftest report.json
```

## 🩺 Troubleshooting
| Problem | Fix |
|---|---|
| "Windows protected your PC" when installing | Click **More info → Run anyway** |
| Edge voices stopped working | Settings → **🔧 Repair voice engine** |
| A hotkey doesn't work | Another app is using it. Pick a different one in Settings. |
| Voice cloning / offline recognition unavailable | Install Python and run `pip install f5-tts faster-whisper` |
| No sound from a voice | Turn on **Auto-match the voice to the language** in Voice Studio |
| Where's my stuff? | Settings → **📂 Open data folder** |
